# Medusa 26.1.2

Datapack-driven multiplayer Medusa dungeon and boss project for Minecraft Java 26.1.2.

- Gameplay: vanilla datapack only
- Visuals: optional resource pack / ETF / EMF layer
- Runtime: Java 25
- Datapack format: 101.1
- Resource pack format: 84.0

Implementation follows the approved Superpowers design and implementation plan. Natural world generation is intentionally deferred; administrators place temple instances explicitly through the datapack placement function.
