# Fallen Knight 26.1.2

Datapack-driven multiplayer Fallen Knight boss project for Minecraft Java 26.1.2.

- Gameplay: vanilla datapack only
- Visuals: optional resource pack / ETF / EMF layer
- Runtime: Java 25
- Datapack format: 101.1
- Resource pack format: 84.0

The implementation follows the approved Superpowers design/plan and uses static contract tests plus exact 26.1.2 dedicated-server CI. Physical combat-feel checks that require a real player remain manual acceptance gates.
