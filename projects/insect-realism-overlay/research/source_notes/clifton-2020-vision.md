## Why this source matters
Directly relevant to whether screen imagery should affect tiny ant foot placement.

## Measurements / observations extracted
In darkness, flat-ground walking speed dropped only about 5%; step-crossing performance was not significantly altered. Antennal activity changed with terrain structure but not illumination, supporting tactile/proprioceptive priority for close-range walking.

## Units and uncertainty
Speed difference percentage; kinematic/antenna measures as reported.

## What can enter the derived database
Strong rule that ants should not react to UI pixels as if they are obstacles; screen semantics are beneath the glass.

## Conflicts / limitations
Does not imply vision never matters for navigation; it specifically addresses rapid walking/obstacles.
