## Why this source matters
Programmatic route to specimen/taxon/image metadata at scale.

## Measurements / observations extracted
API exposes specimens, taxa and images, including standardized H=head, D=dorsal, P=profile and L=label shot types, plus caste filters such as worker/queen/male.

## Units and uncertainty
Metadata API, not a kinematic dataset.

## What can enter the derived database
Automated specimen/image indexing and consistent view labels for later visual curation.

## What must not be redistributed
Respect AntWeb attribution and re-check each image license.

## Conflicts / limitations
API availability/rate limits can change.
