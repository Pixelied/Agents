# Calibration-source audit rules

R3 separates bibliography presence from calibration permission.

A value can become a Realistic baseline calibration only when:
- source identity is verified;
- species identity matches;
- life stage/caste/sex matches or the transfer is explicitly qualified;
- the experimental context is compatible with the runtime quantity;
- the value is a measurement/distribution rather than a review-scale reference;
- no conflicting primary evidence remains unresolved.

Conditional host, heat, odor, wind, pharmacology, obstacle, predator, or treatment values are retained as assay/context evidence unless the runtime recreates the same condition.
