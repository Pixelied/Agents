# Universal shader diagnostic

This branch derives universal.vsh and universal.fsh from the supplied source at xiaoyu777-coder/VapeV4.21@5a6ff6ca04c62f32aebf6eee0c983c1a1a5602c4. The fragment function bodies are unchanged; only version/location declarations, the entrypoint name and an opaque comparison-background wrapper are adapted. The vertex projection is diagnostic-only (a 7x3 atlas of 64-pixel tiles), not a production coordinate mapping. Each shader mode uses exactly the same 32-float ABI and parameters as the independent local OpenGL reference. The sample set is 63 reference RGB values (3 per mode), from the original shader with RGBA8 quantization then compositing against #102030. This verifies native game shader compilation, indexed draws and output sampling, not the completed client, its general blur/framebuffer lifetime, or Apple Silicon/MoltenVK.
