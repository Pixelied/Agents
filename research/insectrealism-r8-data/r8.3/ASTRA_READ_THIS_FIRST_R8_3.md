# InsectRealism R8.3 — Astra/Codex READ THIS FIRST

R8.3 **replaces R8.2 as the single current implementation/research handoff authority**.

This is not a new project and it is not permission to undo newer verified app/debugging work from the existing Astra conversation/workspace.

## What changed from R8.2

The species decision did **not** get reset. The problem being corrected is the research-data mix.

R8.2 contained about 1 GB of validated exact-species visual/reference media. That was useful for rendering, but far too image-heavy for an implementation handoff.

R8.3 therefore:

- keeps roughly 50% of the best R8.2 visual references rather than deleting nearly all of them;
- prioritizes target-stage labels, resolution, sharpness, provenance and source diversity when selecting images;
- adds actual reusable raw/open study workbooks, tables, source-data files and experimental recordings;
- adds factual published numerical datasets for important studies whose authors did not release reusable raw trajectories/tables;
- separates locomotion/calibration data from contextual life-history/physiology/molecular data;
- indexes valuable copyrighted/reuse-unclear studies and high-speed recordings as remote-only rather than illegally redistributing them;
- keeps explicit evidence gates where trajectory-level data still do not exist.

Use `00_START_HERE/CURRENT_IMPLEMENTATION_PLAN_R8_3.md` as the **single implementation plan**. Do not juggle it with the old R8.2 plan.

## The ant system is unchanged and remains fully in scope

The core ant remains **Linepithema humile**. Preserve and continue:

- realistic mature-worker physical sizing;
- continuous worker morphology/size variation;
- callow workers;
- queens;
- males;
- eggs;
- larvae;
- pupae/brood;
- corrected worker-vs-male larval evidence;
- trails/pheromones;
- recruitment;
- colony/social context;
- realistic development/population timing;
- ant-specific evidence gates.

R8.3 only changes the evidence package for the additional arthropods.

## Current additional arthropods remain

1. adult `Liposcelis bostrychophila`;
2. ~24 h first-instar `Blattella germanica`;
3. adult `Oryzaephilus surinamensis`;
4. optional rare adult `Chelifer cancroides` pseudoscorpion predator.

## Evidence hierarchy

Do not equate file size with calibration authority.

1. Direct target-species + target-stage raw study data measuring the runtime parameter.
2. Direct published numerical measurements/model parameters where raw data were not released.
3. Exact-species experimental recordings, restricted to their stage/context.
4. Contextual exact-species biology datasets.
5. Curated exact-species visual/reference media.
6. Clearly labeled donor transfer or engineering assumptions.

A raw adult cockroach courtship dataset is still not first-instar walking calibration. A 40 KB exact-stage locomotion table can outrank a 500 MB image corpus.

When new R8.3 empirical data materially improve a runtime parameter, document the evidence decision and update the compact profile. Otherwise keep the dataset contextual/validation-only.
