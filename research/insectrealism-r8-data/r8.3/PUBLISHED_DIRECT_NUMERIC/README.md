# R8.3 published direct numerical data

These CSV files are **factual numerical extractions from the cited studies**, used where authors did not release a reusable raw trajectory/table file.

They are not synthetic raw data and they are not reverse-engineered fake trajectories.

Authority classes:

- `published_direct_aggregate`: directly reported measurement/statistic from the target study;
- `published_direct_model_parameter`: model/calibration value explicitly reported by the target study;
- `published_direct_regression`: fitted equation reported by the study;
- `derived_unit_conversion`: transparent unit conversion of a directly reported value.

Where reusable author/repository data exist, those raw files are stored separately under `STUDY_DATA/RAW_OPEN_DATA`.
