## The Argentine-ant system is unchanged

The core remains **Linepithema humile** with the full existing system:
- continuous worker size/morphology variation;
- mature workers and callows;
- queens and males;
- eggs, larvae and pupae/brood;
- colony/social context;
- trails/pheromones and recruitment;
- gradual infestation logic;
- ant-specific evidence gates.

R8.3 changes the **supporting evidence package for the new non-ant arthropods**, not the ant system.

## Current non-ant set

- adult *Liposcelis bostrychophila*;
- ~24 h first-instar *Blattella germanica*;
- adult *Oryzaephilus surinamensis*;
- optional rare adult *Chelifer cancroides* pseudoscorpion predator.

## What changed from R8.2

R8.2 was too dominated by exact-species reference photography.

R8.3:
- keeps about **55%** of the strongest/diverse reference-media files;
- records every removed reference in a dropped-reference manifest so it remains recoverable;
- adds actual study/repository files: XLS/XLSX/CSV, supplementary datasets, behavioral datasets, quantitative morphology/life-history data and study videos where redistribution is allowed;
- separates raw data from published aggregate extracts;
- records inaccessible/copyright-restricted movement datasets as remote-only rather than pretending they are bundled;
- explicitly prevents large genomics archives from padding the bundle simply to increase byte count.

Use the empirical files to calibrate only the variables and stages they actually measure.
